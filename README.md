# uvlhub.io

Repository of feature models in UVL format integrated with Zenodo and flamapy following Open Science principles - Developed by DiversoLab

## Official documentation

You can consult the official documentation of the project at [docs.uvlhub.io](https://docs.uvlhub.io/)

## Plantilla de commits

Para utilizar la plantilla de commits del proyecto, es necesario configurarla previamente mediante el siguiente comando, ejecutado desde la raíz del repositorio:

```bash
git config --local commit.template .github/.gitmessage.txt
```

Una vez configurada, al ejecutar `git commit` se abrirá automáticamente el editor de Git con la plantilla predefinida y las indicaciones necesarias para redactar el mensaje de commit siguiendo las convenciones del proyecto.

Esta configuración solo debe realizarse una vez por repositorio.
